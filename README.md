# 黑马商城（HMall）- 学习用微服务项目

本仓库内容来自 **B 站「黑马程序员」开源项目《黑马商城》**（常见仓库名为 `hmall`，隶属于其微服务教学项目体系）。本仓库仅用于本人学习与复现微服务相关知识点。

## 学习背景

- 学习时间：**2024 年 10 月 – 11 月**
- 用途：微服务相关组件与工程化实践的学习（注册中心/配置中心、网关、鉴权、服务拆分、接口文档等）
- 说明：本仓库并非官方仓库；如需最新与完整资料，请以黑马程序员官方公开视频/仓库为准。

## 项目结构（示例）

该项目包含多个服务模块，例如：

- `hm-gateway`：网关
- `user-service`、`item-service`、`cart-service`、`trade-service`、`pay-service`：业务服务
- `hm-common`、`hm-api`：通用与 API 依赖模块

## 敏感信息处理

为避免将本地环境信息或潜在敏感内容上传到公开仓库，本仓库已做清理与脱敏处理：

- 已移除 `**/target/`、`logs/`、`.idea/`、`*.iml` 等不应入库内容
- 已移除 `**/application-local.yaml`（以 `*.example` 示例文件替代）
- 已移除 `**/*.jks`（以 `*.example` 占位文件替代）
- 配置中的 Nacos 地址与 JWT 密钥密码改为可配置占位（示例：`${hm.nacos.addr:127.0.0.1:8848}`、`${hm.jwt.password:change-me}`）

## 本地运行提示

1. 复制各模块的 `application-local.yaml.example` 为 `application-local.yaml` 并修改数据库连接信息。
2. 如需要 `hmall.jks`，请按 `*.jks.example` 中提示自行生成本地 keystore。
3. 启动依赖（如 Nacos、MySQL 等）后再启动各服务模块。
